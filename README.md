# DBMS Lab Practice Repository 🗃️
This is a collection of SQL practice codes covering all fundamental Database Management System concepts implemented during my lab sessions.

## Features ✨

- 📚 Covers essential DBMS topics:
  - Database creation & management
  - SQL queries (DDL, DML, DCL, TCL)
  - Joins, Subqueries & Views
  - Stored Procedures & Functions
  - Triggers & Cursors
  - Normalization examples
  - Transactions & Concurrency control
- 🏗️ Structured by concepts:
  - Basic to advanced SQL operations
  - Problem statements with solutions
  - Sample databases with test cases
- 💡 Practical implementations:
  - Real-world scenario based exercises
  - Performance optimization examples
  - Error handling demonstrations
